# Customer Management System

A comprehensive C# application for managing customer relationships and data.

## Overview

The Customer Management System is a robust solution designed to help businesses efficiently manage their customer information, interactions, and relationships.

## Features

- Customer profile management
- Data organization and retrieval
- Customer relationship tracking

## Technology Stack

- **Language**: C#
- **.NET Framework**: Built with C# for enterprise-level reliability

## Getting Started

### Prerequisites

- .NET Framework or .NET Core installed
- Visual Studio or Visual Studio Code
- Basic knowledge of C# development

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/liewvk/CustomerManagementSystem.git
   ```

2. Navigate to the project directory:
   ```bash
   cd CustomerManagementSystem
   ```

3. Build the project:
   ```bash
   dotnet build
   ```

4. Run the application:
   ```bash
   dotnet run
   ```
